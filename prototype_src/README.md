# LogiCheck AI | 双主题高保真原型 v2

打开 `LogiCheck_AI_HiFi_Dual_Theme_v2.html` 即可体验，无需安装或部署。

- 登录页卡片右上角、进入系统后顶部右上角，都可以切换 **深色 / 浅色**。
- 配色：深色海军蓝 + 科技青；浅色雾白 + 冷灰蓝 + 科技青。
- 主题选择保存在浏览器本地（若浏览器允许本地存储），刷新时保持。
- 原版交互保留：一键体验案例、货物列表/创建/搜索、查看单证、异常证据联动、人工复核及重新检查。
- 原型不包含真实 AI 接口、真实身份验证和服务器数据库。用户新上传的文件只做本地预览，不会模拟 AI 已解析完成。

推荐使用 Chrome / Edge 打开；设计评审时建议同时体验两种主题的登录、货物列表、工作台与异常详情。
