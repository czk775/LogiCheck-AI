## 二、已实现功能清单

**账号**：登录 / 注册 / 忘记密码（弹窗可开可关）/ 一键演示登录；会话保持与退出；路由守卫带 hydrated 守卫（修复刷新深链接被误踢的缺陷）。

**货物列表**：搜索、状态筛选（全部/草稿/待处理异常/待解析/检查完成）、新建、行菜单、删除二次确认、空态。

**工作台**（状态 → 异常 → 行动优先）：总状态面板、下一步行动、指标卡（单证/异常/字段/规则）、异常列表、单证列表、货物字段卡（含冲突标记）、合规规则清单、处理流程步进、合规免责声明。

**异常处理闭环**：异常详情抽屉（两值对照 / 证据 tab 切换 / 数量行高亮）、字段修正（弹窗默认来源 / 保存留痕）、单证替换（旧证据失效重开异常）、人工复核（记录保留、风险不消除）、重新检查（演示货物执行数量一致性核验；非演示货物明确返回"AI 未接入"，不伪造结果）。

**合规规则**：5 条规则（RED/RoHS/Batteries/WEEE/HS，含官方来源外链）、规则详情抽屉、材料补充人工跟进。

**真实文件**：拖拽/选择上传（pdf/png/jpg/webp/edi/txt）、格式/15MB/空文件校验与拒绝提示、上传状态机推进（uploading→uploaded，**不伪造 parsed**）、IndexedDB 缓存 + 图片原件预览 / EDI 原文预览、失败状态 + 重试、删除确认。

**交互与状态**：刷新深链接恢复（工作台 URL 直达）、退出重登数据保留、Toast 反馈、Esc/遮罩关闭弹窗与抽屉、移动端响应式（390px：侧栏折叠 58px、登录页单列）、`prefers-reduced-motion` 降级、全流程无阻断 JS 异常。

## 五、已知限制

1. 数据存于浏览器本地（localStorage/IndexedDB），隐私模式下降级内存存储，非生产级安全方案。
2. 无真实 AI 能力：演示检查结果为写死的确定性演示数据；真实上传文件不产生提取结果（诚实边界，有意设计）。
3. 未引入单元测试框架，验证以 E2E 断言替代；接后端后可补 Vitest。
4. 界面保留 DEMO BUILD 徽章与演示环境声明（诚实标注，接入真实后端前不建议移除）。

## 六、验收建议（浏览器人工过一遍）

1. `npm install && npm run dev` → 打开 http://localhost:5173
2. 一键演示登录 → 列表搜索/筛选 → 进入 SHP-2026-001 工作台
3. 打开数量冲突异常 → 切换证据 tab → 修正装箱单数量 → 重新检查 → 查看处理记录
4. 记录一条人工复核 → 打开规则抽屉 → 对某规则记录人工意见
5. 新建货物 → 上传一份 PDF/图片/EDI → 查看原件预览 → 删除确认
6. **刷新页面**（深链接保持）→ 退出 → 重登 → 数据仍在
7. 右上角切换浅色主题 → 刷新 → 主题保持 → 切回深色
8. 浏览器开发者工具 Console 确认无红色报错

验收通过后，再按 P0→P1→P2 顺序对接后端。
